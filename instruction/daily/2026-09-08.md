  - 排障「rviz 图像小 / 滚轮缩放无效」：根因是 rviz2 在树莓派上崩溃
    - 树莓派 5 v3d GPU 驱动仅支持 OpenGL 3.1 / GLSL 1.4，rviz2 地图 shader 链接失败导致进程崩溃（日志 `GLSL link result: active samplers...`，进程 EXITED crashed）
    - 解决：给 rviz2 节点加 `additional_env={"LIBGL_ALWAYS_SOFTWARE": "1"}` 强制软件渲染（llvmpipe，OpenGL 4.5），rviz2 稳定运行不崩溃
    - 注意：软件渲染性能低于硬件渲染，但 2D 地图 + 激光点云可接受
  - 排障「rviz 地图显示小、滚轮无效果」的真正根因（用户定位）：`TopDownOrtho` 视图的 `Scale` 参数才是缩放因子（默认 50，值越大显示越大），之前误以为 `Distance` 控制缩放。已把 `slam.rviz` 的 `Scale` 改为 200
