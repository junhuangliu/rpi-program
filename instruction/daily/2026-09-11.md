### 3. 雷达反装坐标系排障（当日最长一条，最终修正成功）
- 实况：雷达逆装（激光 x+ 指向机器人后方），需让 slam 实际坐标"前方=x 正"
- **根因（关键）**：`static_transform_publisher` 旧式参数顺序是 **`x y z yaw pitch roll parent child`**，
  先前把 π 写在第 6 位（roll）→ 实际是绕 **x 轴** 180°，yaw 恒 0，导致前后/旋转方向全反
  （曾误判为 laser_scan_matcher 或 inverted 问题；inverted true/false 两轮实测均无效佐证根因不在扫描方向）
- 最终正确配置（`fun/slam_launch.py`）：
  - 静态 TF：`["0","0","0","3.14159265","0","0","laser","base_link"]`，父=laser、子=base_link（绕 z 180°，yaw 在第 4 位）
  - matcher `base_frame=laser`（发 odom→laser）；slam_toolbox `base_frame: laser`（yaml）
  - TF 链 **map→odom→laser→base_link** 单链（laser 唯一父）；若 static 以 base_link 为父会双父 → TF 树断裂（"two or more unconnected trees"）
- 修后实测验证（全部通过）：
  - 前推 ~7cm → map x 由 0 变 -0.074（当时 yaw≈180°，前进=map -x，正确）
  - 顺转 90° → yaw 179.8°→87.6°（减小 92°，右手系顺转为负，量值准确）
  - `./control.sh oc` 前方障碍全部 x 为正（0.27/0.32/0.83m，矩形 0.2~1.0 内）
- **`#POS` 帧 yaw 改导航惯例**（0=朝北、顺时针为正）：`fun/bridge.py` 对 `quat_to_yaw(q)` 取负
- 备注：inverted 保持默认 false；open_lidar 未再叠加 inverted

### 4. 新增 MaixCAM 数据接收节点（TCP → ROS2 话题 + 查询服务）

- 端口/接口：监听 `0.0.0.0:8080`（`-p` 可改）；MaixCAM 按行（`\n`）发送、UTF-8
  - 话题 `/maixcam/data`（std_msgs/String）
  - 服务 `/maixcam/query`（std_srvs/srv/Trigger）→ 最近一条；从未收到返回 `success=false, "NO_DATA"`
- 节点：新建 `fun/maixcam.py`（参考用户两段 socket 示例合并）：
  - accept 循环 + 每连接一线程，**持续监听支持任意重连**（进程不退出）

  - 每条数据：缓存（加锁）+ 终端打印 + 追加 `maixcam.log` + 发布话题
  - Ctrl+C 优雅退出（acceptor 用 1s accept 超时 + Event）
- 接入：`start.py` 注册 `maixcam`；`control.sh` 增 `maixcam`（FUNCS_ALL/usage/svc 服务列表）+ 快捷 `mq`
- 实测验证（全通过）：
  - `printf 'MSG_A\nMSG_B\n' | nc 127.0.0.1 8080` → 服务查询返回 MSG_B（最新）
  - 断开后重连再发 → 查询返回新数据（重连正常）
  - `ros2 topic echo /maixcam/data` 收到数据（注意要留足 discovery 时间，或加 `--qos-reliability reliable`）
  - `./control.sh mq` 返回最近数据
